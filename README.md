# Hello Demo

一个用于学习 GitHub 常规工作流的练习项目。

## 目标

通过实践掌握以下 Git/GitHub 核心操作：

- 创建和管理分支（branch）
- 提交（commit）与推送（push）
- 发起 Pull Request（PR）
- 代码审查（Code Review）
- 合并（merge）与解决冲突
- Issue 跟踪与协作

## 工作流步骤

1. **Fork** 目标仓库到个人账号
2. **Clone** 到本地，创建功能分支（`git checkout -b feature/xxx`）
3. 开发完成后 **Commit** 并 **Push** 到远程分支
4. 发起 **Pull Request**，等待 Code Review
5. 审查通过后 **Merge** 到主分支
6. 及时 **Sync** 上游仓库，保持分支最新
